# Controls

IridescentCraft ships **one curated set of default keybinds** for its ~450 mods, so every important ability, menu, and tool has its own working key out of the box — no two gameplay functions fight over the same button, and nothing you need is left unbound. Fresh installs get this layout automatically. Everything remains **fully rebindable** in *Options → Controls → Key Binds* (use the search box — there are a lot of entries).

**Already playing and want the new layout?** Open *Options → Controls → Key Binds* and click **Reset Keys** (bottom of the screen). That resets every bind to the *pack* defaults below while keeping all your graphics and sound settings. (Individual `Reset` buttons work per-key too.)

## Good to know

- **In menus, keys are separate.** GUI-only shortcuts (JEI's R/U/A, crafting-tweaks K, trash slot T/Delete, storage sorting) deliberately share letters with in-world actions — they only fire inside screens and never conflict with gameplay.
- **Hold-Alt is a shared "radial" convention.** Iron's spell bar, Create's tool menu, Steam 'n' Rails menus, and the Relics ability list all use held Alt on purpose — they're contextual to what you're holding.
- **Some keys are intentionally unbound**: emotes, admin/cheat buttons, per-familiar toggles, quick-cast slots 1–15, and similar optional extras. Bind any of them yourself if you use them — the search box in Controls is your friend.
- **The Codex is live.** Keybind references in the in-game Codex always show your *current* binding, so if you rebind something, the book follows.
