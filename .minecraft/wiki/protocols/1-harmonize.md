# Protocol 1: Harmonize

Full editorial pass to fix contradictions, anachronisms, and tone across all wiki pages.

## Steps

1. Read every page in the wiki
2. Check for contradictions between pages (e.g., different stat values for the same system)
3. Ensure all pages use consistent terminology
4. Verify all cross-references are valid
5. Update any stale "as of" dates
6. Ensure master design document matches implementation status
7. Commit changes
