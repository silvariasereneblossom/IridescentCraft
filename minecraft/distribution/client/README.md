# IridescentCraft — Client Distribution

## Installation (PrismLauncher)
1. Download and extract this folder
2. In PrismLauncher: Add Instance → Import from Folder
3. Point to this extracted folder
4. PrismLauncher will download all mods automatically from the .index metadata
5. Launch and play!

## Installation (Manual)
1. Install Forge 1.20.1-47.4.0
2. Copy the `mods/` folder contents to your instance mods/
3. Copy `config/`, `defaultconfigs/`, `kubejs/`, `global_packs/` to your instance
4. Launch

## Requirements
- Minecraft 1.20.1
- Forge 47.4.0+
- Java 17
- 8-12GB RAM recommended (JVM args: -Xms4G -Xmx10G)

## What is IridescentCraft?
A 420+ mod progression-focused expert-lite modpack with:
- 4-tier progression system (Bronze Age → God-Killer → Space)
- 10 RPG classes, 7 races, 10 Origins
- 29 custom enchantments, 88 Apotheosis affixes
- 27 Tetra modded materials
- 5 Ad Astra planets (post-endgame)
- Custom food/hunger system rewarding diverse cooking
- Inverted End (explore first, fight dragon last)
