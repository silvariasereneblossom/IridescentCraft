    Controls

    IridescentCraft ships one curated set of default keybinds for its ~450 mods. Every important ability, menu, and tool has its own working key from the first launch: no two gameplay functions share a button, and nothing you need is left unbound. Fresh installs get this layout automatically. Every key can still be rebound in Options → Controls → Key Binds; the list is long, so use its search box.

    To move an existing install to this layout, open Options → Controls → Key Binds and click Reset Keys at the bottom of the screen. That resets every bind to the pack defaults below and keeps your graphics and sound settings. Each key also has its own Reset button.

    Good to know

    • In menus, keys are separate. GUI-only shortcuts (JEI's R/U/A, crafting-tweaks K, trash slot T/Delete, storage sorting) share letters with in-world actions on purpose: they only fire inside screens, so they never conflict with gameplay.
    • Holding Alt is a shared "radial" convention. Iron's spell bar, Create's tool menu, Steam 'n' Rails menus, and the Relics ability list all use a held Alt on purpose, and which one opens depends on what you're holding.
    • Some keys are unbound on purpose: emotes, admin/cheat buttons, per-familiar toggles, quick-cast slots 1 to 15, and similar optional extras. Bind any of them yourself if you use them; the search box in Controls finds them.
    • Keybind references in the in-game Codex always show your current binding, so if you rebind something, the book follows.
